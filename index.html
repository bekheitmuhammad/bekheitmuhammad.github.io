AgroVision

AI-powered smart agriculture platform · graduation project · 12-member team · completed June 2025منصة زراعة ذكية بالذكاء الاصطناعي · مشروع تخرج · فريق من 12 عضوًا · اكتمل في يونيو 2025

An AI and IoT platform for precision agriculture. It combines computer vision, sensing, and cloud infrastructure to give farmers real-time crop-health visibility and disease detection, replacing reactive guesswork with data.منصة ذكاء اصطناعي وإنترنت أشياء للزراعة الدقيقة. تجمع بين الرؤية الحاسوبية والاستشعار والبنية السحابية لتمنح المزارعين رؤية فورية لصحة المحاصيل وكشفًا مبكرًا للأمراض، بدل التخمين ورد الفعل المتأخر.

8soil parameters sensed: N-P-K, pH, EC, moisture, temperature, fertilityمعاملات للتربة يتم استشعارها: N-P-K، وpH، وEC، والرطوبة، والحرارة، والخصوبة
3disease-classification models shipped: tomato, potato, and plant IDنماذج لتصنيف الأمراض تم تسليمها: الطماطم والبطاطس وتعريف النبات
95–99%validation accuracy across those three modelsدقة تحقق عبر النماذج الثلاثة

How the system is builtكيف بُني النظام

IoT layerطبقة إنترنت الأشياء

8-in-1 soil sensor, then Raspberry Pi 3 for edge processing, then ESP32 for irrigation control, then Firebase cloud sync, with automated water-pump actuation.حساس تربة 8 في 1، ثم Raspberry Pi 3 للمعالجة على الحافة، ثم ESP32 للتحكم في الري، ثم مزامنة سحابية عبر Firebase، مع تشغيل تلقائي لمضخة المياه.

Backend layerطبقة الخادم

SQL database and application server handling business logic, workflows, and communication between components.قاعدة بيانات SQL وخادم تطبيقات يتولّيان منطق العمل وسير العمليات والتواصل بين المكونات.

AI layerطبقة الذكاء الاصطناعي

Pre-trained TensorFlow disease-classification models served through FastAPI, plus “Khedr,” a Gemini-powered chatbot on a Dockerized local server.نماذج TensorFlow مدرَّبة لتصنيف الأمراض تُقدَّم عبر FastAPI، إضافة إلى «Khedr»، مساعد محادثة يعمل بـ Gemini على خادم محلي داخل Docker.

Frontend layerطبقة الواجهات

React.js web dashboard and Flutter mobile app for real-time monitoring, alerts, and farmer-facing insights.لوحة تحكم ويب بـ React.js وتطبيق موبايل بـ Flutter للمراقبة الفورية والتنبيهات ومعلومات موجّهة للمزارع.

Trained on labeled leaf-image datasets per crop and evaluated with confusion matrices on held-out validation splits.دُرِّبت على مجموعات صور أوراق مصنّفة لكل محصول، وتم تقييمها بمصفوفات الالتباس على بيانات تحقق مستقلة.

Key engineering decisionsأهم القرارات الهندسية

  • Split disease classification into three focused models (tomato, potato, general plant ID) instead of one general model, which pushed validation accuracy into the high 90s on each.قسّمت تصنيف الأمراض إلى ثلاثة نماذج متخصصة (طماطم، بطاطس، تعريف نبات عام) بدل نموذج واحد شامل، فارتفعت دقة التحقق إلى التسعينات المرتفعة في كل منها.
  • Served inference through a Dockerized FastAPI service, decoupling the AI layer from the main backend so it can scale independently.قدّمتُ الاستدلال عبر خدمة FastAPI داخل Docker، لفصل طبقة الذكاء الاصطناعي عن الخادم الرئيسي لتتوسع باستقلالية.
  • Pre-processed data at the edge on the Raspberry Pi before cloud transmission, which cuts network load and keeps the system usable on unreliable rural connections.عالجتُ البيانات على الحافة داخل Raspberry Pi قبل إرسالها إلى السحابة، ما يقلل الحمل على الشبكة ويُبقي النظام صالحًا للعمل مع ضعف الاتصال في الريف.
